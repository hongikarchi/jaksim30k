# MVP 테스트 안내

이 빌드는 **가짜 서버**로 돌아가요. 로그인·카드 등록·AI 판정·결제는 모두 흉내만 내고, 실제 돈은 나가지 않아요. 데이터는 휴대폰 안에만 저장돼요.

## 설치

| 휴대폰 | 방법 | 필요한 것 |
| --- | --- | --- |
| 안드로이드 | 설치 파일(APK) 링크를 받아 설치 | Expo 계정 (무료) |
| 아이폰 | 앱스토어에서 **Expo Go**를 받고, QR 코드로 열기 | Expo 계정 (무료) |
| 아이폰 (정식 설치) | TestFlight | 애플 개발자 계정 (유료, 나중에) |

Expo 계정 준비:
1. https://expo.dev 에서 가입해요.
2. 계정 설정 → Access Tokens에서 토큰을 만들어요.
3. Claude Code 환경 설정(세션 제목 옆 클라우드 환경 메뉴 → Edit)에서 환경 변수 `EXPO_TOKEN`으로 넣어요. 채팅창에는 붙여넣지 마세요.
4. 새 세션에서 "설치 파일 만들어줘"라고 하면 안드로이드 APK 빌드와 아이폰용 Expo Go 링크를 만들어요.

## 개발 메뉴

홈 화면의 **"오늘의 약속" 제목을 길게 누르면** 열려요. 계정 화면 맨 아래 "개발 메뉴"로도 들어갈 수 있어요.

- **시간 이동**: +10분 / +1시간 / +1일, "다음 인증 창이 열리는 순간으로", "열린 창이 닫힌 직후로"
- **판정·결제 결과**: AI 판정(통과·애매·불통과·무작위), 사람 검수 결과, 이의제기 결과, 다음 결제 실패, 다음 업로드 실패
- **지금 처리**: 검수 결과·이의제기 결과를 기다리지 않고 바로 내기
- **자동 인증**: 러닝 기록(5.2km / 3.2km / 수동 입력), 헬스장 머문 시간 보내기
- **감시자**: 초대한 감시자가 수락한 것처럼 만들기
- **예시 데이터**: 대기, 창 열림, 여러 약속 열림, 놓친 날, 결제 실패, 프로 사용자
- **화면 갤러리**: 51개 화면을 번호순으로 모아 보기

## 해볼 흐름

1. **처음 시작**: 시작하기 → 카카오로 계속하기 → 권한 허용 → 미라클모닝 → 금액 → 동의 → 테스트 결제창에서 카드사 고르기 → 홈
2. **인증해서 지키기**: 개발 메뉴 "다음 인증 창이 열리는 순간으로" → 홈 "지금 인증하기" → 촬영 → 제출 → 지킨 날
3. **애매·불통과**: 개발 메뉴에서 AI 판정을 "애매" 또는 "불통과"로 바꾸고 인증 → 판정 확인 중 / 다시 찍기
4. **놓친 날과 이의제기**: 창이 열린 상태에서 "열린 창이 닫힌 직후로" → 놓친 날 화면 → 이의제기
   - "앱이나 카메라 오류"는 바로 결제 취소돼요.
   - 그 외 사유는 개발 메뉴 "이의제기 결과 지금 내기"로 결과를 봐요.
5. **결제**: "+1일"로 결제 시각을 넘기면 결제돼요. "다음 결제 실패시키기"를 켜면 결제 실패 화면으로 가요. 카드를 바꾸면 밀린 금액이 결제돼요.
6. **쉬어가기·금액·시간 수정·끝내기**: 홈의 약속 줄 → 약속 상세
7. **프로**: 계정 → 프로 카드 → 7일 무료 체험. 러닝·헬스장 위치 인증·감시자가 열려요.

## 알려진 한계

- 알림은 휴대폰 로컬 알림이에요. 앱을 한 번 연 뒤 앞으로 48시간치가 예약돼요.
- 앱이 꺼져 있는 동안의 마감·결제 처리는 앱을 다시 열 때 한꺼번에 반영돼요.
- 헬스장 위치 인증과 스트라바 연동은 개발 메뉴로 기록을 보내야 해요.
- 카카오·애플 로그인, 결제, AI 판정은 진짜 백엔드 단계(SPEC 8장 6번)에서 붙여요.
