# 작심삼만원 기획서

2026-09-28 · archibe

## 1. 개요

**작심삼만원** — 지키거나, 내거나.

카드만 등록해 두고, 정해둔 시간 안에 인증하지 못한 날에만 약정 금액이 결제되는 습관 약속 앱이다. 지키면 한 푼도 나가지 않는다.

- **한 줄 정의**: 돈이 걸린 알람시계. 미라클모닝, 러닝, 헬스장, 책읽기, 방청소 같은 매일의 약속을 사진·기록으로 인증한다.
- **대상 사용자**: 혼자 결심만으로는 습관이 무너지는 20~30대 직장인·학생. 앱을 매일 아침 한 번 여는 사용 패턴을 가정한다.
- **벤치마크**: Beeminder·Forfeit식 후불 벌금 구조(선결제 예치 없음), 챌린저스의 인증·판정 경험.
- **플랫폼**: iOS·안드로이드 앱(Expo, TypeScript 하나의 코드).

**MVP 범위**

- 약속 5종: 미라클모닝, 러닝, 헬스장, 책읽기, 방청소
- 사진 인증(앱 내 촬영만) + AI 1차 판정 + 사람 검수
- 후불 카드 과금(PG 빌링키), 이의제기, 결제 실패 처리
- 쉬어가기, 약속 끝내기, 알림 설정
- 프로 구독: 러닝 자동 인증, 헬스장 위치 자동 인증, 감시자 지정, 쉬어가기 월 4번, 7일 무료 체험

**MVP 제외 (다음 단계)**

- 홈 화면·잠금화면 위젯
- 인증해야 꺼지는 알람 (iOS 가능 범위 확인 후)
- 애플 건강·삼성 헬스·스크린타임 연동
- 월간 리포트, 기부 옵션 (하지 않기로 결정)

## 2. 서비스 규칙

모든 약속은 "인증 창 안에 인증하면 지킴, 못 하면 놓침" 하나의 규칙으로 돌아간다. 놓친 날은 24시간 뒤 등록 카드로 결제되고, 그 사이에 이의제기할 수 있다.

### 2.1 약속 종류와 인증 방식

| 약속 | 기본 인증 창 | 기본 요일 | 인증 방식 | 비고 |
| --- | --- | --- | --- | --- |
| 미라클모닝 | 06:00–06:10 | 평일 | 앱 내 촬영 + 랜덤 미션 | |
| 러닝 | 19:00–22:00 | 월수금 | 스트라바 기록 자동 인증 | 프로 전용, 한 번에 5km 이상, 수동 입력 기록 불인정 |
| 헬스장 | 19:00–23:00 | 월수금 | 촬영 + 랜덤 미션, 또는 위치 자동 인증 | 위치 인증은 프로, 머무를 시간 선택(기본 30분) |
| 책읽기 | 00:00–23:59 | 매일 | 쪽 번호가 보이게 촬영 + 한 줄 기록(10자 이상) | 읽는 책은 자동완성 |
| 방청소 | 21:00–23:59 | 매일 | 기준 사진과 같은 각도로 촬영 | 사진으로 확인 가능한 체크리스트만 기준으로 |

- 인증 창은 약속마다 시작~끝 시각으로 정하고, 요일마다 다르게 정할 수 있다.
- 사진은 앱 안에서 바로 찍은 것만 인정한다. 앨범 사진 불가, 촬영 시각을 사진에 새긴다. 셀카·후면 카메라 전환 가능.
- 헬스장 위치 인증: 등록한 위치의 반경 안에 인증 창 동안 누적으로 정한 시간 이상 머물면 인증. 중간에 나갔다 와도 누적.

### 2.2 판정

1. 촬영 → 사진 확인(다시 찍기 / 제출) → AI 1차 판정
2. **통과**: 미션이 확실히 보이면 바로 "지킨 날"
3. **애매**: 어둡거나 흐리면 사람 검수로 넘김. 제출 시점부터 최대 6시간 안에 결과, 그동안 실패로 처리하지 않음
4. **불통과**: 미션이 확실히 안 보이면 "다시 찍기". 인증 창이 열려 있는 동안 재촬영 가능
5. 제출 실패(네트워크): 인증 창 안에 찍은 사진은 연결이 돌아온 뒤 늦게 보내도 인정

### 2.3 결제

- **후불 과금**: 선결제·예치 없음. 카드는 PG 빌링키로 등록, 놓친 날에만 결제.
- **결제 시점**: 인증 창 마감 24시간 뒤. 그 전까지 이의제기 가능.
- **금액 단계**: 1번째 0원(연습) → 2번째 5,000원 → 3번째 10,000원 → 4번째부터 최대 금액. 최대 금액은 10,000 / 20,000 / 30,000(기본) / 50,000 / 100,000원 중 선택.
- 금액은 올리든 내리든 언제든 즉시 바꿀 수 있다.
- **결제 실패**: 72시간 안에 카드를 바꾸지 않으면 새 약속을 만들 수 없다. 카드 변경 시 PG 창으로 바로 이동, 등록 성공 시 밀린 금액 즉시 결제.
- 카드는 계정당 1장, 모든 약속에 공통 적용.

### 2.4 이의제기

- 사유: 앱·카메라 오류 / 인증했는데 실패 처리 / 몸이 아팠음 / 기타(설명 입력)
- **앱·카메라 오류**: 확인 없이 즉시 결제 취소, 지킨 날로 기록, 금액 단계 유지, 연속 기록 유지
- **그 외 사유**: 접수 후 12시간 안에 사람이 검토. 그동안 결제 보류
- 거절 시 사유를 알리고 알림 후 12시간 뒤 결제. 결과에 이의가 있으면 문의로 연결

### 2.5 쉬어가기와 끝내기

- **쉬어가기**: 한 달 1번(프로 4번). 약속이 있는 날 중 오늘부터 선택 가능, 단 그날 인증 창이 닫히기 전까지. 쉬는 날은 결제 없고 연속 기록 유지.
- **끝내기**: 누르는 즉시 종료, 이후 결제 없음. 끝내기 전에 기록을 보여주고 쉬어가기·금액 낮추기·시간 바꾸기를 먼저 제안.

### 2.6 기타

- 만 19세 이상만 가입(카카오·애플 로그인).
- 첫 약속 시작 전 알림·카메라 권한 요청. 위치 권한은 헬스장 위치 인증을 고를 때만 요청("항상 허용").
- 회원 탈퇴 시 진행 중인 약속은 즉시 종료, 결제 예정 금액은 먼저 결제, 이의제기 중인 건은 결과 후 처리.

## 3. BM과 요금

수익은 두 갈래다. 놓친 날의 약정 금액(실패금)은 전부 회사 매출이고, 프로 구독은 "더 확실하게 지키고 싶은 사람"을 위한 고정 수익이다. 실패금을 깎아주는 기능은 팔지 않는다.

| 구분 | 무료 | 프로 |
| --- | --- | --- |
| 약속 개수 | 무제한 | 무제한 |
| 사진 인증 약속(미라클모닝, 헬스장 사진, 책읽기, 방청소) | O | O |
| 러닝 자동 인증(스트라바) | — | O |
| 헬스장 위치 자동 인증 | — | O |
| 감시자 지정(카카오톡 알림) | — | O |
| 쉬어가기 | 월 1번 | 월 4번 |
| 가격 | 0원 | 월 4,900원 / 연 39,000원 |

- **무료 체험**: 7일. 체험 종료 하루 전 알림, 체험 중 언제든 해지.
- **결제 수단 분리**: 프로 구독은 앱스토어·플레이스토어 인앱결제, 실패금은 PG 자동결제(빌링키). 서로 상계하지 않는다.
- **실패금 공개 원칙**: 실패금이 회사 매출이라는 점을 약관과 확인 화면에 명시한다. 기부 옵션은 두지 않는다.
- **프로 잠금**: 무료 사용자가 프로 기능(러닝, 헬스장 위치 인증, 감시자)을 누르면 잠금 시트 → 프로 구독으로 연결.

**다음 단계 프로 후보**: 홈·잠금화면 위젯, 인증해야 꺼지는 알람, 애플 건강·삼성 헬스·스크린타임 연동.

## 4. 화면 목록과 흐름

화면은 51개이고, 번호는 wireframes/SCREENS.md와 같다. 하루의 흐름은 인증 창을 기준으로 두 갈래로 나뉜다.

**하루의 흐름**

- 인증 갈래: 홈(인증 창 열림) → 촬영과 사진 확인 → AI 판정 → 통과(지킨 날) / 애매(사람 검수, 6시간 안에 통과 또는 놓침) / 불통과(다시 찍기, 인증 창 안이면 다시 촬영)

### 5.2 공통 컴포넌트와 규칙

- **화면 틀**: 390×844, 좌우 여백 20~24, 하단 여백 32. 메인 버튼은 항상 화면 맨 아래 같은 위치.
- **메인 버튼**: 높이 56, 모서리 14, 검정 바탕 흰 글자. 비활성은 회색(#C9C8C3).
- **라벨 문구**: 모든 라벨은 한국어, 본문 서체로 쓴다. 와이어프레임의 NO ALARM, TODAY'S MISSION, WEEKLY GOAL 같은 영어 라벨은 한국어로 바꾼다. IBM Plex Mono는 PRO 뱃지에만 쓴다.
- **보조 버튼**: 흰 바탕 + 테두리 56·14, 또는 44 높이 회색 텍스트 버튼("나중에 할게요").
- **하단 설명 글**: 13px, text-2, 가운데 정렬, 버튼 묶음 안에서 버튼과 10 간격.
- **작은 액션 버튼**: 검정 알약 32·16(예약, 끝내기, 변경, 해제, 인증).
- **시계 카드**: 검정(대기) 또는 주황(창 열림·다시 찍기) 카드. 왼쪽 위 라벨(남은 시간, 완료 시간, 판정 예정까지 등), 오른쪽 위 LED + 약속 이름, 도트 숫자 75px(시:분:초 8자리), 아래 제목 20px + 부연 14px.
- **통계 카드 쌍**: 왼쪽 검정 + 주황 도트 숫자, 오른쪽 흰색 + 검정 도트 숫자, 크기 같음.
- **목록 줄**: LED 점 + 이름/설명 + 오른쪽 상태. 창 열림 LED는 주황 + 빛 번짐.
- **선택 표시**: 모두 동그라미. 선택 = 검정 채움 + 흰 체크 + 2px 검정 테두리, 해제 = 흰 원 + border(#C9C8C3) 1px 테두리. 와이어프레임의 2px 테두리는 따르지 않는다.
- **시간 입력**: 검정 바 안의 주황 도트 숫자(06:00 ~ 06:10). 누르면 하단 시트에서 시·분 −/+ 조절(분은 10분 단위 + 59). 인증 시간, 머무를 시간, 약속 수정에 공통.
- **하단 시트**: 반투명 검정 덮개 + 위쪽 모서리 28의 흰 패널, 제목 + ×, 맨 아래 메인 버튼.
- **카메라 틀**: 상단 닫기·제목, 주황 미션 배너(한 줄), 네 모서리 표시가 있는 촬영 영역, 영역 아래쪽 촬영 시각, 하단 96 높이 바(남은 시간 / 셔터 / 카메라 전환).
- **사진 카드**: 왼쪽 세로 썸네일 + 오른쪽 항목 두 줄.
- **스켈레톤**: 결과 화면과 같은 구조, 채워질 자리는 회색 막대.

## 6. 푸시 알림

돈이나 판정과 관련된 알림은 끌 수 없고, 나머지는 알림 설정에서 켜고 끈다. 통과 결과는 앱 화면에서 바로 보이므로 푸시를 보내지 않는다.

| 알림 | 보내는 때 | 제목 | 내용 | 끄기 |
| --- | --- | --- | --- | --- |
| 인증 시작 전 | 인증 창 열리기 N분 전(5·10·30분, 기본 10분) | 10분 뒤 미라클모닝 인증이 열려요 | 06:00–06:10, 5,000원이 걸려 있어요 | 가능 |
| 인증 창 열림 | 좁은 창 약속의 시작 시각 | 지금 인증하세요 | 06:10에 닫혀요 | 가능 |
| 마감 임박 | 마감 N분 전, 미인증일 때만(기본 5분) | 5분 남았어요 | 지금 인증하지 않으면 5,000원이 결제돼요 | 가능 |
| 넓은 창 마감 | 마감 3시간 전, 미인증일 때만 | 책읽기 마감까지 3시간 | 오늘 23:59까지 기록을 남겨주세요 | 가능 |
| 다시 찍기 | AI 불통과 | 사진을 다시 찍어주세요 | 06:10 전에 다시 찍으면 돼요 | 불가 |
| 판정 결과 | 사람 검수 완료 | 판정이 끝났어요 | 오늘 미라클모닝은 지킨 걸로 했어요 | 불가 |
| 놓친 날 | 마감 경과 | 오늘 약속을 놓쳤어요 | 내일 06:10에 5,000원이 결제돼요. 억울하면 이의제기할 수 있어요 | 불가 |
| 자동 인증 실패 | 러닝·헬스장 조건 미달 | 러닝 거리가 모자랐어요 | 3.2km를 달렸어요. 이의제기는 내일까지 가능해요 | 불가 |
| 결제 완료 | 실패금 결제 직후 | 5,000원이 결제됐어요 | 미라클모닝, 9월 3일 | 불가 |
| 결제 실패 | 결제 실패 | 결제가 안 됐어요 | 3일 안에 카드를 바꿔주세요 | 불가 |
| 이의제기 결과 | 승인·거절 | 이의제기가 받아들여졌어요 / 받아들여지지 않았어요 | 5,000원 결제를 취소했어요 / 오늘 21:40에 결제돼요 | 불가 |
| 쉬어가는 날 | 쉬어가기 당일 아침 | 오늘은 쉬어가는 날이에요 | 인증하지 않아도 기록이 이어져요 | 가능 |
| 감시자 연결 | 감시자 수락 | [이름]님이 감시자가 됐어요 | 약속을 놓치면 [이름]님에게 알려드려요 | 불가 |
| 체험 종료 예고 | 무료 체험 종료 하루 전 | 내일 프로 체험이 끝나요 | 계속 쓰면 월 4,900원이 결제돼요 | 불가 |
| 혜택과 소식 | 이벤트, 새 기능 | 내용에 따라 | 내용에 따라 | 가능(기본 꺼짐) |

감시자에게 가는 메시지는 푸시가 아니라 카카오톡 알림톡이다(초대 메시지, 놓친 날 알림, "매일 결과" 선택 시 지킨 날 알림).

## 7. 백엔드 기능

핵심은 "인증 창" 단위의 스케줄링이다. 약속마다 날짜별 인증 창(occurrence)을 미리 만들고, 알림·마감 판정·결제를 모두 그 창의 시각에 맞춰 예약한다.

### 7.1 도메인 모델

| 모델 | 주요 필드 |
| --- | --- |
| User | 카카오·애플 ID, 생년(만 19세 확인), 구독 상태, 체험 종료일, 알림 설정 |
| PaymentMethod | PG 빌링키, 카드사, 끝 4자리 (계정당 1장) |
| Promise | 종류, 요일별 인증 창, 인증 방식, 최대 금액, 연속 기록, 실패 횟수, 쉬어가기 사용 횟수, 상태 |
| Occurrence | 약속, 날짜, 창 시작·끝, 상태(대기·열림·지킴·검수 중·놓침·쉼·면제) |
| Submission | 사진, 촬영 시각, 미션, AI 결과·점수, 검수 결과, 책 제목·한 줄 |
| AutoEvidence | 스트라바 활동(거리, 시작 시각) 또는 위치 체류 기록(누적 분) |
| Dispute | 사유, 설명, 상태, 검토자, 결과 사유, 처리 시각 |
| Charge | 금액, 예정 시각, 상태(예정·보류·완료·실패·취소), PG 거래 ID |
| Watcher | 약속, 카카오 수신자, 알림 범위(놓친 날만·매일), 연결 상태 |
| ConsentLog | 약속별 동의 항목, 시각, 약관 버전 |

### 7.2 스케줄러와 배치

- **창 생성**: 매일 자정 이후 다음 7일치 Occurrence 생성, 약속 수정 시 미래 창 재생성.
- **알림 예약**: 창 시작 N분 전, 시작, 마감 N분 전(미인증일 때만 발송), 넓은 창 마감 3시간 전.
- **마감 처리**: 창 마감 시각에 미인증 → 놓침 확정, Charge를 마감+24시간으로 예약, 감시자 알림 발송.
- **결제 배치**: 예정 시각 도래 + 이의제기 없음·거절 → 빌링키 결제. 실패 시 72시간 유예 후 새 약속 제한.
- **자동 인증 수집**: 스트라바 웹훅으로 활동 수신 → 창 안·거리 조건 판정. 위치는 앱이 지오펜스 진입·이탈을 보내고 서버가 누적 분 계산.
- **체험 종료**: 종료 하루 전 알림, 스토어 구독 상태는 영수증 검증·서버 알림(App Store Server Notifications, Google RTDN)으로 동기화.

### 7.3 판정 파이프라인

1. 업로드(촬영 시각·기기 정보 포함) → 촬영 시각이 창 안인지 확인
2. AI 판정: 미션 수행 여부 + 약속별 조건(쪽 번호, 기준 사진 각도 유사도) → 통과 / 애매 / 불통과
3. 애매 → 검수 큐, 6시간 안에 결과. 그동안 Charge 보류
4. 모든 사진은 이의제기 대응을 위해 보관(보관 기간은 개인정보 처리방침에 명시)

### 7.4 관리자 검수 도구 (웹)

- 검수 큐: 애매 판정 사진, 이의제기 건을 마감 시각 순으로
- 한 화면에서 사진·미션·촬영 시각·기준 사진(방청소)·사용자 이의 내용 확인 후 통과/놓침, 승인/거절 + 사유 선택
- 결제 내역 조회와 수동 취소, 사용자별 기록 조회
- 검수 SLA(6시간·12시간) 초과 경고

## 8. 기술 스택과 개발 순서

앱은 Expo(React Native) + TypeScript 하나로 iOS·안드로이드를 함께 낸다. 아침 알림과 앱 내 카메라 제어가 서비스의 핵심이라 웹앱(PWA) 대신 이 선택을 했다.

- **앱**: Expo, TypeScript, Expo Router(화면 이동, 알림에서 화면으로 바로 이동), expo-camera, expo-notifications, expo-location(지오펜스)
- **결제**: 토스페이먼츠 등 PG 자동결제(빌링키), 구독은 스토어 인앱결제
- **연동**: 카카오·애플 로그인, 스트라바 API·웹훅, 카카오 알림톡

**개발 순서**

1. 프로젝트 셋업: Expo + TypeScript
2. 토큰: 색, 서체(DotGothic16, IBM Plex Sans KR, IBM Plex Mono), 간격, 모서리
3. 컴포넌트: 시계 카드, 목록 줄, 버튼, 선택 표시, 시간 바 + 시간 시트, 하단 시트, 카메라 틀, 사진 카드, 금액 단계 막대, 달력
4. 화면 갤러리(개발용): 모든 화면을 한 곳에서 비교
5. 화면: 약속 만들기 → 홈과 인증 → 판정 → 놓친 날과 이의제기 → 약속과 계정
6. 백엔드: 로그인 → 카드 등록 → 창 생성·알림 예약 → 인증·AI 판정·검수 → 마감·결제 배치 → 자동 인증(스트라바, 위치) → 구독 → 관리자 검수 도구

## 9. 개발 전 확인할 것

아래 항목은 설계상 가정일 뿐 확인된 사실이 아니다. 출시 전에 전문가·심사 기관에 확인해야 한다.

- [ ] **사행성 여부**: 실패금이 다른 사용자에게 가지 않고 회사 매출이 되는 구조라 챌린저스 수준의 방어 논리는 가능하지만, 명시적 유권해석은 없다. 형사·핀테크 변호사 자문 필요.
- [ ] **전자금융거래법**: 예치금 없는 후불 카드 과금이라 선불업 등록이 필요 없다고 가정. 확인 필요.
- [ ] **PG 자동결제 심사**: "미이행 시 부과되는 약정 이용료"로 명목을 정하고, 약속별 동의 로그를 남긴다. PG사별 심사 조건 확인.
- [ ] **앱스토어 결제 규칙**: 실패금(외부 PG 결제)이 심사를 통과하는지, 구독은 인앱결제 대상이며 수수료가 붙는다.
- [ ] **iOS 백그라운드 위치**: 헬스장 위치 인증에 "항상 허용"이 필요. 심사용 사용 목적 설명 준비.
- [ ] **인증해야 꺼지는 알람**: iOS에서 서드파티 알람으로 구현 가능한 범위 확인(다음 단계 기능).
- [ ] **개인정보**: 인증 사진·위치·카카오 수신자 정보의 보관 기간과 처리방침.
- [ ] **미정 항목**: 운영 시간, 기록 보관 기간, AI 판정 기준치.
